# #168 旅行者向けコネクティビティブランド12年（$412k, グローバル）— スキップ

## サービスの中身
海外旅行者向けの通信（SIM/eSIM/WiFi系）を複数チャネルで販売するB2C/B2B2Cブランド。親会社の方針転換で売却。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $331.5k / $70.6k（21%） |
| 先月 | **$10.5k / -$4.4k（赤字）** |
| 顧客数 / ARR | 5,000+ / $0（取引型） |
| 年成長率 | 「+10%」表記 |
| 売却理由 | 新事業・ライフスタイル＋親会社の方針転換 |

| 創業 / チーム | 2014年1月（12.6年）/ 2-20人 |

## 検算で見つけた矛盾
- **先月$10.5k×12 = $126k vs TTM $331.5k（-62%）＋先月赤字** — 「+10%成長」表記と真逆の急落。#119型の崩壊隠し

## 判断
**スキップ**。キャリア直販eSIM（Airalo・Ubigi・キャリア公式）に飲まれる中間流通ブランドの末期。取引型で溜まるものなし。
