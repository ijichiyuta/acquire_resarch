# #003 ショート動画クリッピングSaaS（$170k, US Florida）— 見送り

**サービスの中身**
長尺動画をアップすると、TikTok / YouTube Shorts / Reels 向けの縦型クリップを自動生成するツール。字幕付け、切り出し位置の提案まで自動。B2C＋B2Bの両建てサブスク。2023年7月創業、チーム2〜20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $136.7k / $43.6k（利益率32%） |
| 先月 | 売上$8.9k / 利益$6.3k（**利益率71%**） |
| 顧客数 / ARR | 251〜500 / $117k |
| 客単価 | 月$20〜39 🔵 |
| 年成長率 | **-32%** 🔴 |
| チャーン | 10%以上（低下傾向） |
| 売却理由 | Starting a new venture / Lack of time。「2025年8月以降このプロダクトは放置し、別のSaaSに全振り」と明記 |
| スタック | **Vercel / Supabase / Cloudflare / GCP / AWS** 🔵（優太さんの環境そのもの） |
| 競合 | Capcut, AutoShorts, Captions AI, Klap, Submagic, VEED |
| 価格 | $170k（3.9x profit / 1.2x rev）。根拠は「Acquireの平均推奨値」のみ |

**この事業の強み**
- 客単価 月$20〜39。4件中でも上位。動画制作は「時間を買う」用途なので単価が取れる
- スタックが完全に現代的。引き継いでも技術負債にならない数少ない案件
- 売主が「放置していた」と正直に開示している

**差別化ポイント：消滅した**
これが本質。2023年の創業時点では「自動クリップ生成」自体が差別化だったが、**Capcut（ByteDance）が同じ機能を無料で出した瞬間に差別化が消えた**。競合欄に6社並んでいる時点で、機能はすでにコモディティ。放置したから落ちたのではなく、放置しても落ちなかった部分がなかった。

**判断: 見送り。** ただし利益率32%→71%は「広告を止めたから利益が出て、同時に売上が落ちた」＝**溶けていく氷**。

**教訓（逆向き）**
**ツール単体には値がつかない。** 同じ機能でも、配給網や案件を持っている側が使えば価値になる。[[vad-platform]] の ClipForge が示しているのはまさにこれで、価値はツールではなく BACKSTAGE という出口の側にある。**単体SaaSとして外販する方向には伸ばさない。**
