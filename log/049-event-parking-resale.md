# #049 イベント駐車券転売事業（$700k, US Oregon）— スキップ

## サービスの中身
イベント駐車券を仕入れてチケットマーケットプレイスで転売するリモートオペレーション事業。ブローカーPOSと「新規参入者には使えない仕入れルート」が資産。2021年6月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.2M / $377.4k（31%） |
| 先月 | $247k / $55k（TTMの21% — イベント季節性） |
| 顧客数 | 5,000+（B2C購入者） / 在庫$40k |
| 年成長率 | +97% |
| チャーン | 概念不適合（転売） |
| 売却理由 | 金銭＋新規事業 |
| スタック | Squarespace / Airtable / Slack（ノーコード運用） |
| 競合 | 「独立系の駐車券転売業者」 |
| 価格 | $700k（1.9x profit / <1x rev） |
| 創業 / チーム | 2021年6月 / 2-20人（経過62ヶ月） |

## 検算で見つけた矛盾
- 「GMV $1.1M」と「TTM revenue $1.2M」の関係が不明瞭（グロス計上の疑い）。転売業でGMV≒revenueなら手数料事業ではなく在庫転売そのもの

## 判断
**スキップ**。仕入れルートという属人資産に依存する転売オペレーション。マーケットプレイス規約変更で消える位置。

## タイムマシン評価
**不可**。日本はチケット不正転売禁止法の隣接領域で法的リスク、akippa等の駐車場シェアも既存。

なし
