# #250 グリーン表示検証SaaS（$59k, 欧州）— 見送り

## サービスの中身
EC・ブランドの環境訴求（グリーンクレーム）の根拠検証・コンプライアンス表示SaaS。EUのグリーンウォッシング規制対応レーン。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $69.3k / $41.3k（60%） |
| 先月 | $5.1k / $4.4k（×12 = $61k ≈ ARR ✓） |
| 顧客 / ARR | 51-100 / $69k（単価 月$57〜113） |
| チャーン | **0-1%** |
| 年成長率 | **+2%** |
| 価格 | $59k（1.4x profit — また安値警報） |
| 資金調達 | Angel入り / モデル欄9項目全部盛り |

## 判断
**見送り**。制度駆動（EU Green Claims Directive）×チャーン0-1%は案7/9/10と同じ勝ち筋の匂いだが、**規制の本場EUで+2%しか伸びていない＝規制の執行が実際には始まっていない**ことの証left。制度駆動は「施行日」が全て、の教材。

## わかりやすく言うと
「この商品はエコ、の根拠を示せ」という欧州規制対応ツール。規制が本当に牙を剥くまで客は動かない — 案10（ストレスチェック2028施行）の「窓のタイミング」の重要性を裏から証明。

## 持ち帰った型
観測: **制度駆動SaaSは「施行前の仕込み」と「執行開始」の時差で死ねる**。日本の制度案件（案7/9/10/13）は施行日と執行実態の確認を検証項目に追加
