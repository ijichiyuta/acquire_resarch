# #026 SMB向けAIカスタマーサービスSaaS（$90k, US Delaware）— スキップ

## サービスの中身
中小企業が自社データで顧客対応AIエージェントを構築するSaaS。「単純なチャットボットより深い文脈理解」を謳う。B2Bサブスク。2023年2月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $88.9k / **-$12.8k** |
| 先月 | $4.1k / **+$8.8k（利益＞売上の会計不整合）** |
| 顧客数 / ARR | 51〜100 / $57k |
| 客単価 | 月$48〜93 |
| 年成長率 | **-41%** |
| チャーン | 5-10%（低下傾向） |
| 売却理由 | 新規事業＋時間不足 |
| スタック | **Vercel / OpenAI / Supabase / Pinecone / Webflow**（ユーザーと同一系） |
| 資金調達 | ブートストラップ |
| 競合 | Chatbase, Watermelon AI |
| 価格 | $90k（<1x profit / 1x rev） |
| 創業 / チーム | 2023年2月 / 2-20人（経過42ヶ月） |

## 検算で見つけた矛盾
- **見出し「$104k TTM Revenue」vs プラットフォーム$88.9k（17%盛り）**
- **先月: 売上$4.1kで利益$8.8k** — 売上より利益が大きい。返金・経費戻し・未計上のどれかで、P&Lの信頼性が低い
- 成長-41%: 崩壊局面。1x revでも「安いから買う」対象ではない

## 判断
**スキップ**。今日3件目のAIカスタマーサービス出品（#013 -26%、#023、#026 -41%）。**同一カテゴリの出品が固まって出るのはカテゴリ退潮のシグナル** — acquire.comは「差別化が消えた後」の市場であり、独立系AIカスタマーサポートは今まさにその波。スタックが自分と同じ（Supabase/Vercel）である点は、同じ道具で作っても差別化にならないことの実物教材。

## 持ち帰った型
なし（メタ気づきのみ: カテゴリの群れ＝退潮シグナル）
