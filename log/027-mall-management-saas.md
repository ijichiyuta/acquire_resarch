# #027 ショッピングモール管理SaaS（$6.1M, Finland）— 見送り／型4の大型成立例

## サービスの中身
ショッピングセンター・商業不動産オーナー向けに、テナント通信・リース管理・運営・来店者エンゲージメントを一本化するB2B SaaS。北欧300+施設・テナント2.5万・複数年のフレーム契約。2008年創業（18年）、チーム21-100人、経営陣運営済み。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $2.3M / $393.1k（17%） |
| 先月 | $179.2k / $140.7k（79%） |
| 顧客数 / ARR | 1,000〜5,000表示 / **「$6M」表示（下記の通り疑義）** |
| 客単価 | 施設単位なら月$600前後（実効ARR÷300施設） |
| 年成長率 | +20% |

| 売却理由 | ライフスタイル（創業者フルイグジット、経営陣は残る） |
| スタック | 不明（モジュラー型クラウド） |
| 資金調達 | ブートストラップ |
| 競合 | 記載視認できず |

## 検算で見つけた矛盾
- **「$6M ARR」vs 先月×12 = $2.15M（2.8倍の乖離）**。TTM $2.3Mとは整合するので、実効ランレートは$2.2M前後。複数年フレーム契約の**残存契約総額（TCV）をARRと呼んでいる**疑いが濃厚。ARR偽装の新パターンとしてcriteriaに追加
- 15.6x profitは利益率17%（人員21-100人）の重さの裏返し。「~3x revenueはPropTech相場」という主張は、実効ARRベースなら2.8xで概ね正しい

## この事業の強み
18年×複数年契約×チャーン1-3%。テナント通信と請求という**商業施設の日常業務そのもの**に乗っており、剥がれようがない。経営陣運営でオーナー依存が低い。

## 判断
**見送り**（規模・チーム数とも個人運用の対象外）。データとしては**型4の最大成立例**: この構造は$2M+売上・18年・組織運営までスケールすることを実証。

## 持ち帰った型
型4に追記: 少数×高単価×埋め込みは「施設単位のフレーム契約」形態で大型化できる。ただし人員も比例して増え利益率は17%まで落ちる — 個人でやるなら10〜50社で止める設計（従来結論）が正しい。
