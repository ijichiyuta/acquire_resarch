# #048 サロン向けPOS SaaS（$600k, Austria）— スキップ

## サービスの中身
美容室・コスメスタジオ・グルーミング店向けのクラウドPOS（予約・会計・顧客連絡・ハードウェア対応）。DACH圏。2022年5月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $120k / **$1k（利益率0.8%）** |
| 先月 | $4k / $0（×12 = $48k vs ARR $120k — 2.5倍乖離、下降中） |
| 顧客数 / ARR | 51-100 / $120k |
| 客単価 | 月$100〜196 |
| 年成長率 | +15%表示（実態は下降） |
| チャーン | **0-1%（POS埋め込みの傍証）** |
| 売却理由 | 金銭 |
| 資金調達 | 借入 |
| 競合 | comhair, studiolution 等（独語圏の実勢） |
| 価格 | **$600k（600x profit / 5x revenue）** |
| 創業 / チーム | 2022年5月 / 2-20人（経過51ヶ月） |

## 検算で見つけた矛盾
- **先月×12 = $48k vs ARR表示$120k** — ARRの2.5倍盛りまたは急落中
- **600x profit / 5x rev** は50件で最も非現実な値付け。KeyAssetsの「Patents」も盛り

## 判断
**スキップ**。値付けが交渉の入口にならない。データ価値はPOS埋め込み×チャーン0-1%の3例目（#012スマレジ論・#030・#048）のみ。

## タイムマシン評価
**不可**。日本のサロンはサロンボード（ホットペッパー）とリザービアで飽和。

## 持ち帰った型
なし
