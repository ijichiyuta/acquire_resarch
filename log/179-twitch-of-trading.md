# #179 「株トレードのTwitch」配信＋教育（$900k, US）— スキップ

## サービスの中身
トレーダーのライブ配信・講座・スキャナ設定の会員制。**Lifetime Access $3,299** の買い切り販売が主力。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.1M / $690.4k（63%） |
| 先月 | $64.1k / $32.4k（×12 = $769k、-30%） |

| 年成長率 | -10% |

## 検算で見つけた矛盾
- TTM $1.1M vs ARR $361k — 差額$700kはライフタイム販売。**将来の継続収益を前借りして「利益率63%」に見せている**。買った瞬間からこの先食い分は入らない

## 判断
**スキップ**。トレード教育のグルビジネス＋ライフタイム先食い＋Business challenges。創業者の顔で売れており、顔は譲渡できない。

## わかりやすく言うと
- **どんなサービス**: 有名トレーダーの取引画面を生配信で見られる会員制＋講座
- **強み**: 63%の利益率（ただし先食り）
- **競合優位性**: 創業者個人のカリスマ。それは売り物にならない
- **日本で始めるなら**: 不可（投資助言業の登録が必要な際どいレーン）

## 持ち帰った型
なし。観測: **「ライフタイム販売でARRとTTMが乖離」は先食いの検知式として追加**
