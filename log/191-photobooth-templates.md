# #191 フォトブース業者向けテンプレートSaaS（$1.6M, US）— スキップ

## サービスの中身
イベントのフォトブース運営業者向けに、撮影画面・合成フレームのテンプレートをサブスク提供。7.3年運営。

| 項目 | 値 |

| TTM売上 / 利益 | $271.8k / $239.8k（**88%**） |
| 先月 | $22.6k / $20k（×12 = $271k ✓一致） |
| 顧客数 / ARR | 1,000-5,000 / $272k（単価 月$4.5〜23） |
| チャーン | 1-3% Stable |
| 年成長率 | 0% |
| 売却理由 | **「売却するつもりで作った」と自白** |
| 価格 | $1.6M（**6.9x profit / 6.1x rev**） |
| 創業 / チーム | 2019年5月（7.3年）/ 2-20人 |

## 判断
**スキップ**。売上6.1倍の値付けは今バッチ最大の空想。単価も月$23未満で本命ライン未達。ただし構造の観測価値は高い（下記）。

## わかりやすく言うと
- **どんなサービス**: 結婚式やイベントで見る「その場で写真が撮れるブース」の運営業者に、画面デザインのテンプレを月額で売る
- **強み**: 利益率88%・解約率1-3%。**業者は毎回のイベントで必ず使う「プロの日常作業ツール」**（#071型）
- **競合優位性**: ニッチすぎて大手が来ない
- **日本で始めるなら**: フォトブース市場自体が日本では小さい。不可。ただし「業者の毎回作業に食い込むテンプレ・素材」という型は#071の追認

## 持ち帰った型
なし（#071「プロの日常作業ツール」の追認標本: マイクロ縦でも88%マージン×チャーン1-3%が成立。ただし単価が上がらない縦だった — #146と同じ限界）
