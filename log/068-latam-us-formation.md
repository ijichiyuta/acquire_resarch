# #068 LATAM向け米国法人設立ワンストップ（$125k, US NY）— スキップ／制度手続き型の2例目

## サービスの中身
中南米の起業家向けに、米国LLC/C-Corp設立・EIN取得・米国住所・ネオバンク口座開設をコンシェルジュ型で一括代行。年次タックスリターンと会計ツール紹介の継続収益つき。2022年8月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $496.1k / $115k（23%） |
| 先月 | $44k / $12k |
| 顧客数 / ARR | 欄が機能せず / **ARR $0表示**（設立は単発、税務は年次） |
| 客単価 | 案件単価型 |
| 年成長率 | 非表示 |
| チャーン | 10%+表示 |
| 売却理由 | ライフスタイル＋金銭 |
| スタック | Next.js / React Native / MongoDB |
| 資金調達 | ブートストラップ＋政府系グラント |
| 価格 | **$125k（1.1x profit / 0.25x rev）** |
| 創業 / チーム | 2022年8月 / 2-20人（経過48ヶ月） |

## 判断
**スキップ**。設立という単発手続き＋紹介収入の複合で継続性が薄く、1.1x profitの値付けが実態の自白。コンシェルジュ＝労働。

## タイムマシン評価
**概念は転用可・ただし士業の壁**。日本版=「外国人起業家の日本法人設立＋在留資格『経営・管理』対応」は、2025年の経営管理ビザ厳格化（資本金要件引上げ）で需要と単価が上がっている領域だが、登記は司法書士・在留は行政書士の独占。**案9（外国人雇用管理）に「設立系行政書士との連携」として合流させるのが正しい**。

## 持ち帰った型
制度手続き型（#031と同族）の2例目。単発手続きは「年次の継続義務（税務・更新）」とセットにして初めてSaaSになる、という設計指針
