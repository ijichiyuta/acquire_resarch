# #207 マーケティング自動化SaaS 13年（$7.7M, US）— スキップ

## サービスの中身
顧客エンゲージメント・オーディエンス育成のマーケ自動化SaaS。累計10万社、2013年から13年運営。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $3.6M / $1.7M（47%） |
| 先月 | $297k / $143k（×12 = $3.6M ✓一致） |
| 顧客 / チャーン | 1,000-5,000社 / 1-3% |
| 年成長率 | +15% |
| 価格 | $7.7M（4.4x profit / 2.1x rev） |

## 判断
**スキップ**。事業として今バッチ最健全（13年・チャーン1-3%・数字が一致・倍率も実勢圏）だが、$7.7Mは個人買収の対象外。マーケ自動化の生き残りは「10万社に薄く」でなく実態は少数中単価に収斂している点だけメモ。

## わかりやすく言うと
Mailchimpの隙間で13年生き残ったマーケ自動化ツール。数字に嘘がなく値付けも常識的 — つまり良い事業は正しい値段で売られる（掘り出し物は存在しない）の見本。

## 持ち帰った型
なし（「健全な出品は正しく高い」の標本）
