# #012 実店舗小売向け顧客エンゲージメントSaaS（$1.3M, US NY）— 見送り／型4の成立3例目

## サービスの中身
実店舗小売向けに、メール/SMSマーケ・ロイヤルティ・クライアンテリング・SNS予約投稿を一本化。**POSとECに接続**して自動アウトリーチとパーソナライズを実行。B2Bサブスク。2019年1月創業、チーム2-20人。

| 項目 | 値 |

| TTM売上 / 利益 | $1.2M / $211.1k（利益率18%） |
| 先月 | $143k / $27k（19%） |

| 客単価 | **月$1,000〜1,961（全17件で最高）** |
| 年成長率 | +67% |
| チャーン | 3-5%（**上昇傾向**） |
| 売却理由 | 新規事業＋ライフスタイル＋金銭 |

## 検算で見つけた矛盾
- 先月×12 = $1.716M vs ARR $1.2M（1.4倍）。成長67%のタイムラグでは説明しきれず、サービス売上か一時収益の混在を疑う
- 1.1x revenue は今回見た中で最安倍率。理由は説明可能: 利益率18%（人件費重い）、VC/エンジェル入りの資本構成、チャーン上昇中
- 「2020年からの技術提携」「再構築より買収が安い統合ライブラリ」という値付けロジックは検証不能だが、方向としては筋が通る

## この事業の強み
**POS統合ライブラリ**。店のレジと顧客データに食い込んでおり、剥がすには運用の作り直しが要る。月$1,000超を51-100社から取れているのはこの埋め込みの対価。

## 差別化ポイント
あり（統合の厚み）。ただしチャーン3-5%が「上昇中」なのは亀裂。小売店は法人といっても廃業・業態転換が多く、#005（人事）#006（不動産業者）ほど顧客自体が安定しない。

## 判断
**見送り**（$1.3Mは対象外・VC入り資本構成も小規模買収に不向き）。ただし構造データとして重要。

## 持ち帰った型
型4の成立3例目として追記: **埋め込みの実装が「POS統合」でも成立する**（#005=業務手順、#006=取引フロー、#012=システム統合）。教訓: 顧客セグメント自体の生存率も低チャーンの前提条件（小売はSMBの中でも廃業率が高く、チャーンの床が高い）。
