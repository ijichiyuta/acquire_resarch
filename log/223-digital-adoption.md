# #223 エンタープライズ向けデジタルアダプション（$127k, US）— 見送り

## サービスの中身
大企業の社内システム定着化（操作ガイド・ROI計測）SaaS（WalkMe系）。Fortune100企業の受賞歴を主張。年払い一括＋導入フィー。2015年創業。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $476.9k / $176.1k（37%） |
| 先月 | $16.4k（年払いモデルなので月次はデコボコ） |
| 顧客 / ARR | **10-50社 / $450k（単価 月$750〜3,750）** |
| 年成長率 | +50% |
| 価格 | **$127k（利益の0.72倍・売上の0.27倍）** |
| 創業 | 2015年10月（10.8年）/ 2-20人 |

## 検算で見つけた矛盾
- **年間利益$176kの事業を$127kで売る** — 健全なら絶対に成立しない価格。開示に出ない何か（上位1〜2社への収益集中、大型契約の非更新確定、創業者への属人依存）があると考えるのが#140則
- 少数×高単価×10.8年という表面は型4そのもの — だからこそ安さの説明がつかないことが決定的

## 判断
**見送り**。表面数値は今バッチ最良級だが、価格が「何かが壊れている」ことを自白している。WalkMe/Pendoの寡占レーンでエンタープライズ営業前提という点も基準5赤。

## わかりやすく言うと
大企業に「新しい社内ツールの使い方を画面上でガイドする」仕組みを売る会社。年間利益より安い売値は、宝くじではなく地雷の値段。

## 持ち帰った型
なし（#140「安さは警報」の最良の追試。型4の見た目でも価格が矛盾したら降りる）
