# #073 VR研修ソリューション（$2.1M, US Georgia）— スキップ

## サービスの中身
企業・教育機関向けのVR職業訓練。ハード販売＋教育機関向け**ライフタイム・ライセンス（約$40K/件）**＋サブスクレンタルのハイブリッド。2017年1月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.3M / $644.1k（50%） |
| 先月 | **$0 / $0** |
| 顧客数 / ARR | 1,000-5,000 / **ARR $0（正直開示）** |
| 年成長率 | +10% |
| チャーン | 3-5%表示（買切りなので概念不適合） |
| 売却理由 | 金銭 |
| 価格 | $2.1M（3.3x profit / 1.7x rev） |
| 創業 / チーム | 2017年1月 / 2-20人（経過115ヶ月） |

## 検算で見つけた矛盾
- **先月売上$0** — ライフタイムライセンス型の宿命で、パイプラインが空になると売上もゼロになる（#025の先月$0と同型）
- ARR $0なのに「SaaS」カテゴリ出品

## 判断
**スキップ**。一発大型ライセンス＋ハード販売は「継続性スペクトラム」の買切り側で、TTM $1.3Mでも来月の保証がない。

## タイムマシン評価
**不可**。日本のVR研修は積木製作等の制作会社が既に厚く、ハード在庫と営業チーム前提。

## 持ち帰った型
なし（ライフタイムライセンスの罠: 高利益率に見えて継続性ゼロ、のサンプル）
