# #159 履歴書→内定 伴走プラットフォーム（$1.3M, US）— スキップ

## サービスの中身
求職者向けに履歴書作成から内定サインまでをAI＋人間の専門家チームで伴走するB2Cサービス。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.1M / $190k（17%） |
| 先月 | $102k / $15k |
| 顧客数 / ARR | 500-999 / **$0（取引型）** |
| 年成長率 | +93% |
| チャーン | 3-5%（取引型なので意味は薄い） |
| 売却理由 | 新事業 / Bootstrapped |
| 競合 | TopResume 他 |
| 価格 | $1.3M（6.8x profit / 1.2x rev） |
| 創業 / チーム | 2023年10月（34ヶ月）/ 2-20人 |

## 検算で見つけた矛盾
- 数字自体は整合（先月×12 = $1.22M、+93%成長と噛み合う）
- ただしARR $0＝**内定が出たら客がいなくなる**構造。売上は毎月新規獲得で作り直し

## 判断
**スキップ**。①B2C ②取引型（溜まらない）③「expert team」の人件費込み17%マージン＝実態は人力サービス。成長93%は本物だが、うちの型（少数×高単価×継続）と正反対。

## わかりやすく言うと
- **どんなサービス**: 「転職成功までまるごと面倒見ます」パッケージ。AIが書類を作り、人間のコーチが面接対策
- **強み**: 成長率93%と$1.1Mの規模。就活の痛みは深い
- **競合優位性**: 弱い。転職支援は人材紹介会社が無料でやる（企業から手数料を取るので）
- **日本で始めるなら**: 不可。日本は人材紹介（成功報酬型）が無料で同じことをやるため、求職者課金モデルは構造的に負ける
