# #014 集団訴訟和解金請求アプリ（$2.8M, US California）— スキップ

## サービスの中身
米国消費者が自分に該当するクラスアクション和解金を見つけて請求できる iOS/Android アプリ。週次/年次サブスク＋法律事務所への請求者リード販売（アフィリエイト）の二本柱。2025年8月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.1M / $804.8k（利益率73%） |
| 先月 | $106.8k / $82.8k（78%） |
| 顧客数 / ARR | 課金5,000+（DL 513k, MAU 10-25k）/ ARR ~$1.22M |
| 客単価 | **月$5〜20**（課金者数の開示次第。下記矛盾参照） |
| 年成長率 | +145%（ただし創業12ヶ月のランプ） |
| チャーン | 非開示（DAU/MAU 10%と週課金モデルから高チャーン推定） |
| 売却理由 | 新規事業 |
| スタック | React Native / TypeScript / Vercel / OpenAI / Next.js |
| 資金調達 | ブートストラップ |
| 競合 | Settlemate, Payme（無名のみ。**無料代替=公式請求サイトを未記載**） |
| 価格 | $2.8M（3.5x profit / 2.5x rev） |
| 創業 / チーム | 2025年8月 / 2-20人（経過12ヶ月） |

## 検算で見つけた矛盾
- **課金者数が2箇所で食い違う**: プラットフォーム欄「PAYING USERS 5,000+」 vs 価格根拠欄「~19,500 paying subscribers」— 約4倍の差
- **TTM売上も食い違う**: プラットフォーム$1.1M vs 説明文「~$905K TTM proceeds」（18%差）
- ARR「~$1.22M（6月ピーク$1.83M）」— **ピーク比-33%で下降中**。145%成長の見出しと逆行
- アフィリエイト収益が塊状（5月単月で$141K = TTMの13%）— サブスクと言いつつ収益の相当部分がリード販売
- 週課金＝B2C煽り型サブスクの典型。無料で請求できる公式手続きの有料ラッパーという構造批判にさらされやすい

## この事業の強み
制度（クラスアクション）×未回収資金という強いフック。インストール→課金転換6.8%は高い。法律事務所トップ5との提携、11万件のメールリスト。

## 差別化ポイント
薄い。データは公開情報の集約で、参入障壁はASOと提携のみ。ピークアウトの兆候が既に出ている。

## 判断
**スキップ**。客単価は月$5〜20のB2C圏、数字の食い違いが2箇所、ARR下降中。日本にはクラスアクション制度が実質存在しない（消費者裁判手続特例法は件数極小）ため転用先もない。

## 持ち帰った型
なし。GoTall事例への補足のみ: **「サブスク＋リード販売の二本柱」はB2Cアプリの収益を1.5〜2倍にする**（ただし収益が塊状になり、サブスク倍率での売却時に割り引かれる）。
