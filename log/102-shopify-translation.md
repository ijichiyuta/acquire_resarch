# #102 Shopify多言語翻訳アプリ（Built for Shopify）（$5M, US Florida）— 見送り／エコシステム系列の最大成立例

## サービスの中身
Shopifyストアを240+言語にAI翻訳（商品説明・ナビ・チェックアウトまで）するアプリ。フリープラン＋$10〜500/月の段階課金。Built for Shopify認証・NRR 101%。2016年9月創業（10年）、チーム21-100人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.5M / $1.2M（**EBITDA 85%**） |
| 先月 | $138.7k / $106.1k（×12 = $1.66M vs ARR $1.3M — 成長分の乖離） |
| 顧客数 / ARR | **5,000+店 / $1.3M** |
| 客単価 | 月$22（多数×低単価×エコシステム） |
| 年成長率 | +17% |
| チャーン | **1-3%（安定）** |
| 売却理由 | 新規事業 |
| 資金調達 | ブートストラップ |
| 価格 | $5M（4.3x profit / 3.4x rev） |
| 創業 / チーム | 2016年9月 / 21-100人（経過119ヶ月） |

## 検算で見つけた矛盾
- EBITDA 85%とチーム21-100人の同居 — サポートを外部契約者で回している構造と推定（DD確認事項）

## 判断
**見送り**（$5M規模）。**Shopifyアプリ系列（#009/#022/#057/#075）の最大成立例・5例目**: 10年・5,000店・チャーン1-3%。Shopify公式の無料翻訳（Translate & Adapt）が存在しても機能深度で勝ち続けている＝**公式機能と共存できるアプリの実例**（#009の吸収リスク議論に対する反対側のデータ）。

## タイムマシン評価
**不可**。グローバルアプリが日本のShopifyストアにも直接届くカテゴリ。むしろ**案6が「言語」でなく「商習慣（掛け率・締め支払）」を選んだ判断の正しさを裏づける**——言語はグローバル勢が解けるが、商習慣は解けない。
