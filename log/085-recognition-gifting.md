# #085 エンタープライズ表彰・ギフト配布SaaS（$3.8M, Canada）— 見送り

## サービスの中身
企業が従業員・顧客・パートナーへの記念日表彰・一括eギフト・パーソナライズ報酬を自動化するプラットフォーム。HR・広報・オペレーション部門の手作業を除去。2022年12月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.4M / $991.9k（**71%**、recast） |
| 先月 | $100.9k / **$100.9k（利益＝売上の会計異常）** |
| 顧客数 / ARR | 500〜999 / $975k |
| 客単価 | 月$81〜163 |
| 年成長率 | +400%（経過44ヶ月のランプ） |
| チャーン | 0-1%（低下傾向） |
| 売却理由 | ライフスタイル |
| スタック | Shopify / AWS / TypeScript |
| 競合 | Achievers, Kudos, Awardco, Tango（大手を正直に記載） |
| 価格 | $3.8M（3.8x profit / 2.7x rev） |
| 創業 / チーム | 2022年12月 / 2-20人（経過44ヶ月） |

## 検算で見つけた矛盾
- **先月の利益＝売上（$100.9k）** — 経費ゼロの月は存在しない。ギフトカード原価のネット計上・ブレークage（未使用残高）会計の可能性が高く、収益認識の実態がDDの最重要論点
- 先月×12 = $1.21M vs ARR $975k — ギフト取扱高の混在疑い

## 判断
**見送り**。#010（表彰・研修は溜まらない）と逆のチャーン0-1%を主張するが、ギフト「配布業務」への埋め込みは説明がつく一方、会計の透明性が低く額面では信用できない。

## タイムマシン評価
**不可**。日本は Unipos / RECOG / giftee for Business 等で飽和。

## 持ち帰った型
なし（ギフトカード系の収益認識は常に疑う、を開示類型に追加）
