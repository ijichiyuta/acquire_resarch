# #030 ホスピタリティ向け業務管理ソフト（$210k, Nigeria）— スキップ

## サービスの中身
ホテル・レストラン・バー・小売・ガソリンスタンド向けのPOS＋在庫＋P&L＋監査の業務管理ソフト。導入・研修の一時金（$300〜2,000）＋年額サブスク（$250〜700）。顧客の99%がナイジェリア。2022年5月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $80k / $60k（75%） |
| 先月 | $6k / $4k |
| 顧客数 / ARR | 101〜250 / **$30k** |
| 客単価 | サブスク分は**月$10〜25**（平均年$250） |
| 年成長率 | +80% |
| チャーン | **10%+（上昇傾向）** |
| 売却理由 | Other＋金銭（「PMFしたので次へ」） |
| スタック | Flutter / Node.js / MySQL / Scala / Firebase |
| 資金調達 | ブートストラップ |
| 競合 | 記載視認できず |
| 価格 | $210k（3.5x profit / 2.6x rev — ただし下記参照） |
| 創業 / チーム | 2022年5月 / 2-20人（経過51ヶ月） |

## 検算で見つけた矛盾
- **TTM $80kのうちサブスクは$30k（38%）。残り62%は導入・研修の一時金** — 取引型混入の典型。サブスクベースでは $210k ÷ $30k = **7x ARR** で、表示倍率（2.6x rev）の見かけより遥かに高い
- 検算: 101-250顧客 × 年$250 ≒ $25k-62k → ARR $30k は整合。数字は正直で、構造が弱いだけ
- 「PMFした」という主張とチャーン10%+上昇は両立しない

## 判断
**スキップ**。実効7x ARR、チャーン悪化、通貨・地理リスク（収益は現地通貨建て）、運用不能。

## 持ち帰った型
なし。教訓のみ: **導入フィーは導入コスト回収の道具であって、収益の主軸にすると倍率がつかない**（designs.md の初期費設計は「回収」に留める現方針が正しい）。
