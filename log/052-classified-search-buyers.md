# #052 業者向け中古仕入れ横断検索（$650k, UK）— 見送り／型2の追認

## サービスの中身
FB Marketplace・eBay・Craigslist・Gumtree等を横断監視し、中古販売業者（車・スマホ・家具の仕入れ業者）に高速アラートと重複・詐欺除去済みの統合結果を出すB2Bツール。2023年11月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $470k / $100k（21%、粗利65%） |
| 先月 | $49k / $15k（×12 = $588k ≒ ARR ✓） |
| 顧客数 / ARR | 500〜999 / $600k |
| 客単価 | 月$50〜100 |
| 年成長率 | +76% |
| チャーン | **10%+（安定）** — 売主自ら「高額顧客ほど残る」と開示 |
| 売却理由 | 新規事業 |
| スタック | Django / Python / PHP / Azure / Flutter |
| 資金調達 | ブートストラップ |
| 競合 | Swoopa, Ivy Flip |
| 価格 | $650k（6.5x profit / 1.4x rev — 検算一致） |
| 創業 / チーム | 2023年11月 / 2-20人（経過33ヶ月） |

## 検算で見つけた矛盾
- 数字は整合。構造リスクが本体: **収益基盤がスクレイピングで、FB/eBayに遮断されたら消える**（#021のプラットフォーム本体リスクと同型）

## 判断
**見送り**。「稼ぐ道具（仕入れ）は単価が取れる」という型2の追認。ただし低価格層のチャーン10%+と規約リスク。

## タイムマシン評価
**条件付き〜不可**。日本版=ヤフオク・メルカリ・ジモティー横断の古物商向け仕入れアラートだが、①オークファン（上場）が相場・仕入れで既に厚い ②メルカリは規約でスクレイピング禁止 — 規約リスクは日本の方が厳しい。持ち込まない。

## 持ち帰った型
なし（型2「稼ぐ道具は費用対効果で売れる」の追認データのみ）
