# #158 日次キュレーションSNS投稿SaaS（$3.3M, US）— スキップ

## サービスの中身
中小企業向けに毎日のSNS投稿コンテンツを配信。エンド26,000店、投稿累計990万件。1999年創業の27年もの。販売は代理店チャネル（ライセンス＋DIY広告コミッション）。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.3M / **$38k（2.9%）** |
| 先月 | $141k / $5.2k |
| 顧客数 / ARR | チャネル51-100社（エンド26,000）/ $950k |
| 年成長率 | +5% |
| チャーン | 5-10% Stable |
| 売却理由 | 「経営陣が新オーナーを探している」/ **VC入り** |
| 価格 | $3.3M（**85.5x profit** / 2.5x rev） |
| 創業 / チーム | **1999年9月（27年）**/ 2-20人 |

## 検算で見つけた矛盾
- **85.5x profit = 空想倍率の新記録**（#129の83.3xを更新）
- 先月$141k×12 = $1.69M vs TTM $1.3M（+30%）— 直近が強いのはチャネル決済のタイミングか。ARR $950kとの差も含め、3つの数字が別方向を向いている
- エンド26,000店で利益$38k = 1店あたり年$1.5の利益

## 判断
**スキップ**。27年やって利益率2.9%のチャネルビジネスに85.5xは成立しない。「多数×低単価」を代理店挟みでやった場合の終着点standardsを示す標本。

## わかりやすく言うと
- **どんなサービス**: 「今日投稿するネタ」を毎日配信するサービスを、広告代理店経由で町の店に売る
- **強み**: 27年の生存とエンド2.6万店の規模
- **競合優位性**: 消滅方向。CanvaとChatGPTが同じことを無料圏でやる時代に入った
- **日本で始めるなら**: 不可。#158自体が「規模があっても利益が出ない」ことの証明
