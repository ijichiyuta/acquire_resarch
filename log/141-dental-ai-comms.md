# #141 歯科医院向けAI患者コミュニケーション（$115k, US California）— 見送り

## サービスの中身
歯科医院のフロント業務（電話応対・予約・患者連絡）を会話AIで自動化する縦特化SaaS。歯科PMS（practice management system）と連携。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $55.8k / $29.2k（52%） |
| 先月 | $5k / $2.6k（52%） |
| 顧客数 / ARR | **<10** / $60k |
| 客単価 | 月$500〜1,000+ |
| 年成長率 | +60%（経過14ヶ月なので参考値） |
| チャーン | 1-3% Stable（顧客10未満で統計的意味なし） |
| 売却理由 | 家族事情＋ライフスタイル変化 |
| スタック | Python / Node / React / OpenAI |
| 資金調達 | Bootstrapped |
| 競合 | Arini / Dentina / Getviva（小規模のみ列挙） |
| 価格 | $115k（3.9x profit / 2.1x rev — 検算OK） |
| 創業 / チーム | 2024年6月（経過14ヶ月）/ 2-20人 |

## 検算で見つけた矛盾
- 数字自体はクリーン: 先月$5k×12 = $60k = ARR $60k ✓、利益率TTM/先月とも52% ✓、倍率検算 ✓
- ただし競合欄に本当の大手（Weave=上場・歯科コミュニケーション、TrueLark、NexHealth等）を書いていない
- Asking price reasoning が「dedicated sales teamでスケールする前提」と自白 = 集客チャネル未確立

## この事業の強み
数字の整合性が取れた縦特化AI。単価が月$500超で「法人の業務プロセスに乗る」構造。歯科業界誌への掲載実績。

## 差別化ポイント
薄い。米国はWeave/TrueLark/Arini等がひしめく激戦区で、PMS連携も各社標準装備。

## 判断
**見送り**。数字はクリーンだが①顧客10未満・ARR $60kは事業と呼べる規模でなく$115kはプロダクト代 ②集客は営業チーム前提（基準5赤）③激戦区で差別化なし。

## わかりやすく言うと
- **どんなサービス**: 歯科医院の「電話番」をAIに置き換えるサービス。予約の受付・変更・リマインドをAIが電話で自動対応し、受付スタッフの負担を減らす。医院あたり月7〜15万円
- **強み**: 解約されにくい構造（予約データが中に溜まる）で、単価も法人向けとして十分高い。売上と顧客数の数字に嘘がなかった
- **競合優位性**: なし。米国では同種サービスが乱立しており、上場企業（Weave）もいる
- **日本で始めるなら**: 開発自体はAI支援で3〜6ヶ月・100万円以下でも可能だが、**日本もすでに激戦区**。電話がらくだ（アポツール連携）・ペイたんコール・SmartCall for Dental・IVRy歯科版などが既に存在し、空白がない

## タイムマシン評価
**不可**。日本語競合が明確に3社以上（電話がらくだ / ペイたんコール / SmartCall for Dental / IVRy歯科LP / CSエージェント歯科）。歯科×AI電話はむしろ日本の方が製品化が進んでいる。

## 持ち帰った型
なし。観測: **「縦特化AI電話受付」は日米とも既に商品カテゴリ化しており、個人の後発参入余地は消滅**。#134の「定例×縦特化なら生きる」は成立しているが、その席はもう埋まっている。
