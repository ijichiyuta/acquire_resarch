# #288 カスタムLMS 12年（エンタープライズ3社）（$75k, US）— スキップ

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $83.2k / $12.4k（15%） |
| 顧客 / ARR | **3社** / $83k（単価 月$2,300/社・チャーン0-1%） |
| 成長 | 0% / 2014年創業・MEANスタック |
| 価格 | $75k（6x profit） |

## 判断
**スキップ**。「少数×高単価×ゼロチャーン」の極小版に見えるが、①3社は「少数」でなく「集中」（1社離脱=売上-33%）②利益率15%＝カスタム保守の人件費が本体 ③12年もののMEANスタック保守を職として買う話。型4には「少数」の下限がある、という教材。

## わかりやすく言うと
大企業3社専用の学習システムを12年守っている会社。買うのは事業ではなく「3社のシステム管理人」の椅子。

## 持ち帰った型
なし（**型4の精緻化: 「少数×高単価」の少数には下限がある（10社未満は集中リスク）**）
