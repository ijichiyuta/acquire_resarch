# #002 ECセラー向けSEO/AI/競合リサーチSaaS（$149.8k, France）— 買うのは見送り／型はアタリ

**サービスの中身**
EC事業者向けに、SEO分析・競合リサーチ・AI支援を1つのサブスクにまとめたプラットフォーム。個別ツールを何本も契約する代わりに、月額1本で済ませる「束ね売り」型。2024年7月創業、1人運営。

**この事業の強み**
- **束ね売りという構造そのもの**。単機能ツールより解約されにくく、値上げの余地もある
- 顧客が「稼ぐために使う」道具なので、費用対効果を計算して払ってくれる。趣味ツールより単価が取れる
- +200%成長は本物。需要があることは証明されている

**差別化ポイント：弱い**
束ねている点は良いが、束ねる中身自体はどれも代替可能。実際の競合は Helium 10 / Jungle Scout / Semrush で、そこには何も書かれていない。チャーン10%超は「使ってみたが他でもいい」と判断された結果。

**見送りの理由**
- 価格が約2,200万円。射程外
- **利益率95% → 62%**。売上が伸びるほどコストが増える構造（AI推論費が濃厚）
- Key Assets に特許・在庫・商標。2024年創業のソロSaaSではあり得ず、開示の信頼性が下がる

**拾った点**: TTM $36.1k に対し ARR $72k のズレは、急成長中なら正常。#001 のズレとは意味が逆。
