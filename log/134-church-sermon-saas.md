# #134 教会説教→SNSコンテンツ変換SaaS（$500k, US Delaware）— 見送り／型3の例外を発見

## サービスの中身
日曜の説教を1回アップすると、文字起こし→キーモーメント抽出→字幕→1週間分のSNS投稿・メール・議論用設問に変換。教会のコミュニケーション担当を増強する。2024年10月創業（22ヶ月）、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $274.6k / $119.6k（44%） |
| 先月 | $14.6k / $1.2k（×12 = $175k ≒ ARR ✓） |
| 顧客数 / ARR | 教会101〜250 / $180k |
| 客単価 | **月$60〜148** |
| 年成長率 | +375%（ランプ） |
| チャーン | **3-5%（安定）** |
| 売却理由 | **共同創業者の不和**（珍しく率直） |
| 競合 | Sermon Shots, Pulpit AI（縦特化の実勢） |
| 価格 | $500k（4.2x profit / 2.8x ARR） |

## 判断
**見送り**（22ヶ月・米国教会市場固有・創業者不和）。**構造の発見が本体: 型3（切り抜きツール外販は死ぬ）の例外条件**。汎用切り抜き（#003/#062/#089）はCapcutに殺されるが、**「毎週必ず定例コンテンツが発生する縦」への埋め込み**なら月$60-148×チャーン3-5%で生きる。差は機能ではなく「定例業務に組み込まれているか」。

## タイムマシン評価
**教会そのものは不可**（日本の教会市場は極小）。**構造は転用可**: 「定例コンテンツが毎週発生する組織」= 学習塾（授業→保護者向け配信）・スポーツクラブ（試合→ハイライト）・士業（顧問先向け情報発信）。BACKSTAGEでやっているクリップ制作の「縦特化SaaS化」の設計図として案出しに回す。

## 持ち帰った型
**型3の救済条件**（types.mdへ）: ツールを殺すのは汎用性。定例×縦特化×埋め込みなら切り抜きでも型4になる
