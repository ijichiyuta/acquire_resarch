# #154 「βユーザー500人」SaaS（$150k, 国不明）— スキップ

## サービスの中身
見出しは「500βユーザー・紹介率23%・CAC $0.26」のSaaS。実態はライセンシング＋受託収入の会社にβ版SaaSが付いたもの。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $105k / $16k（15%） |
| 先月 | $8.8k / $1.3k |
| 顧客数 / ARR | 10-50 / **$5k** |
| 年成長率 | +23% |
| 売却理由 / 資金調達 | 不明（欄が読み取れず） |
| スタック | **ASP.NET / C# / jQuery / Razor（レガシー）** |
| 価格 | $150k（9.4x profit / 1.4x rev） |
| 創業 / チーム | 2019年2月（7.5年）/ 2-20人 |

## 検算で見つけた矛盾
- **TTM $105k vs ARR $5k** — 売上の95%がサブスクではない（ライセンス/受託）。「SaaS platform」の見出しと実態が別物
- ビジネスモデル欄に Licensing/B2B/B2C/Freemium/Subscription 全部盛り＝焦点がない自白
- SaaS部分の実態は月$400。それに$150k（9.4x profit）は空想

## 判断
**スキップ**。見出しのSaaS風化粧を剥がすと受託会社。レガシースタック（基準4赤）。

## わかりやすく言うと
- **どんなサービス**: 中身は受託開発・ライセンス販売の会社。「β版のSaaSに500人いる」を看板にしている
- **強み**: 7年半生き延びた受託の顧客関係
- **競合優位性**: 評価不能（SaaSとしては売上月$400）
- **日本で始めるなら**: 対象外

## 持ち帰った型
なし。観測: 「βユーザー数」「紹介率」「CAC」を見出しに使う出品は、**ARRを見出しに書けない理由がある**
