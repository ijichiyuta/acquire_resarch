# #146 刑事弁護ミティゲーションSaaS（$99k, US）— スキップ

## サービスの中身
刑事弁護士向けに、量刑軽減（mitigation）資料をAIで作成するSaaS。弁護士75人超が利用。ソロ運営6年。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $37.8k / $30k（79%） |
| 先月 | $3k / $2.5k |
| 顧客数 / ARR | 51-100 / $37k |
| 客単価 | 月$31〜60 |
| 年成長率 | +12% |
| チャーン | 3-5% Stable |
| 売却理由 | 時間不足 / Bootstrapped |
| スタック | Azure / OpenAI / Stripe |
| 競合 | **「人間のパラリーガル・専門家」**（ソフト競合なし） |
| 価格 | $99k（3.3x profit / 2.6x rev — 検算OK） |
| 創業 / チーム | 2020年6月（6年）/ ソロ |

## 検算で見つけた矛盾
なし。先月$3k×12 = $36k ≈ ARR $37k ✓。6年でチャーン3-5%・利益率79%の健全なマイクロSaaS。

## 判断
**スキップ**。数字は今バッチ最良クラスだが①客単価月$31〜60で本命ライン（$100）未達 ②市場が米国の量刑実務に固有。

## わかりやすく言うと
- **どんなサービス**: 米国の刑事裁判では、判決前に「被告人の生い立ちや更生可能性」をまとめた資料で刑を軽くする実務が確立している。その資料作成をAIで自動化し弁護士に売る
- **強み**: 競合欄が「人間」。ソフト不在の隙間を6年間ソロで守り、解約率3-5%
- **競合優位性**: 縦特化ゆえ大手が来ない小ささが防壁。逆に言えば市場が小さい
- **日本で始めるなら**: **不可**。日本の刑事弁護は国選中心で支払意欲が薄く、量刑ミティゲーション資料の制度慣行自体がない（#145と同じ「前提インフラ不在」型）

## 持ち帰った型
なし。観測: **「競合欄に人間しかいない」AI置換SaaSは6年生存・チャーン3-5%を実証**（型4変形の良標本。ただし単価が上げられない縦だった）
