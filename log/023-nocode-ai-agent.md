# #023 No-Code AIエージェント構築PF（$255k, Canada）— スキップ

## サービスの中身
企業と代理店向けに、顧客メッセージ・電話対応のAIエージェントをノーコードで構築できるPF。直販＋代理店への白ラベル再販の2セグメント。WhatsApp/FB/IG/Shopify統合済み。2023年6月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $64.2k / $55.2k（86%） |
| 先月 | $7.7k / $6.6k |
| 顧客数 / ARR | 101〜250 / $70k |
| 客単価 | 月$23〜58（LTV $422） |
| 年成長率 | +30% |
| チャーン | 5-10%（低下傾向） |
| 売却理由 | ライフスタイル変更 |
| スタック | React / MongoDB / OpenAI / AWS ほか |
| 資金調達 | ブートストラップ |
| 競合 | Chatbase のみ記載（Voiceflow/Botpress等の実勢より過少） |
| 価格 | $255k（4.6x profit / 4x rev — 検算一致） |
| 創業 / チーム | 2023年6月 / 2-20人（経過38ヶ月） |

## 検算で見つけた矛盾
- 先月×12 = $92.4k vs ARR $70k（1.3倍）— 成長30%のラグでは説明しきれない差。非経常分の混入を疑う
- LTV $422 ÷ 客単価月$23〜58 ≒ 寿命7〜18ヶ月。「低チャーン」の主張と整合しない
- 登録6万人 vs 課金101〜250 = 転換率0.2〜0.4%。フリーミアムの群れは資産にならない実例

## 判断
**スキップ**。汎用AIエージェントビルダーはChatbase/Voiceflow帯で競争過多、$70k ARRに4x revは過大。ただし**白ラベル経由の顧客はチャーンが低いという記述は型4と整合**（代理店の商流に埋まった顧客は剥がれない）。

## 持ち帰った型
なし（微収穫: 埋め込みの第4の実装候補「中間業者の商流に埋まる」。#023では検証不能、次に白ラベル型が出たら確認）
