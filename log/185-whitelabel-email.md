# #185 白ラベル・メールマーケティングSaaS（$109k, 国不明）— 見送り

## サービスの中身
代理店・フランチャイズが自社ブランドで顧客に提供できるメールマーケティング基盤（白ラベルB2B2B）。「Franchise-Ready」。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $400k / $100k（25%） |
| 先月 | $40k / $10k（×12 = $480k、+20%と整合✓） |
| 顧客数 / ARR | 10-50社 / $280k（**単価 月$467〜2,333**） |
| チャーン | 3-5%（見出し「90% retention」） |
| 年成長率 | +30% |
| 売却理由 | 新事業・ライフスタイル / **Angel investment入り** |
| 価格 | **$109k（1.1x profit / 0.27x rev）** |
| 創業 / チーム | 2019年10月（6.9年）/ 2-20人 |

## 検算で見つけた矛盾
- 数字自体は整合。問題は価格: **利益1年分・売上の0.27倍は、数字が本物なら安すぎる**（#140の教訓「安さは警報」）。Angel資本の清算売りか、送信インフラ（IPレピュテーション・deliverability維持）の運用負荷が見た目より重いか
- Webトラフィックデータが2年前で停止

## 判断
**見送り**。構造は今バッチ最良（少数×高単価×白ラベル×低チャーン×6.9年）だが、①価格の安さの説明がつかない ②メール配信インフラは deliverability 管理という専門運用が本体で個人には重い ③Angel資本。

## わかりやすく言うと
- **どんなサービス**: 広告代理店が「うちのメール配信ツールです」と自社ブランドで客に売れる仕組みを、代理店に月7万〜35万円で卸す
- **強み**: 代理店は自分の顧客ごと乗っているので辞めない（維持90%）
- **競合優位性**: 白ラベル層はMailchimp等の大手が本気を出さないニッチ
- **日本で始めるなら**: メール基盤そのものは作らない。ただし**「代理店に月額で卸す白ラベルB2B2B」が6.9年・維持90%で成立する実例**として、案1改三（AIみまもり白ラベル）の構造の傍証になる

## 持ち帰った型
型ではなく傍証: **白ラベルB2B2B（ツールを制作会社・代理店ブランドで卸す）は単価月$500〜2,300・維持90%で成立する**（案1改三・requirements-an1kai3.mdの白ラベル価格設計を裏づけ）
