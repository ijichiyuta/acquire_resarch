# #057 Clover加盟店向けキャッシュディスカウント（$10.2M, US Texas）— 見送り／エコシステム内特化の2例目

## サービスの中身
Clover POS加盟店がカード決済手数料を回収するための現金値引き・二重価格表示ソフト。Clover App Market経由で配布され、100%サブスク。2023年1月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.4M / **$1M（71%）** |
| 先月 | $118.8k / $87.3k |
| 顧客数 / ARR | **5,000+加盟店 / $1M** |
| 客単価 | 月$17前後（多数×低単価） |
| 年成長率 | +97% |
| チャーン | 5-10%（安定） |
| 売却理由 | リタイア |
| スタック | Clover App Market / Clover API / Clover POS |
| 資金調達 | 不明 |
| 競合 | 「Clover App Market内の他のキャッシュディスカウントアプリ」（ストア内競合のみ） |
| 価格 | **$10.2M（9.7x profit / 7.2x rev）** |
| 創業 / チーム | 2023年1月 / 2-20人（経過43ヶ月） |

## 検算で見つけた矛盾
- 先月×12 = $1.43M vs ARR $1M — 成長97%のラグでは説明しきれない差。非経常分の確認が必要
- 7.2x revenueは全件で最高倍率クラス。「決済手数料の回収」という金銭直結の価値が根拠だが強気

## 判断
**見送り**（規模）。**エコシステム内縦特化の2例目**（#051 Salesforce に続きClover）。43ヶ月で5,000加盟店 — ストア販路の配布力と「毎日の会計処理に組み込まれる」埋め込みの組合せ。#009・#051と合わせて、**エコシステム内蔵販路は当たれば最速でスケールする**ことの3点目の証拠。

## タイムマシン評価
**不可**。日本はカード加盟店規約でサーチャージ・カード価格差別が原則制限されており、キャッシュディスカウント文化の制度前提が存在しない。
