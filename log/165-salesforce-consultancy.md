# #165 Salesforceコンサルタンシー（$1.8M, US）— スキップ

## サービスの中身
Salesforce導入・運用改善のコンサル・受託。2009年から17年運営、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.5M / $200k（13%） |
| 先月 | $150k / $10k |
| 顧客数 | 10-50社（契約単価・維持率は非開示） |
| 年成長率 | +10% |
| 売却理由 | 新事業 / Bootstrapped |
| 競合 | OpFocus 等 |
| 価格 | $1.8M（**9.2x profit** / 1.2x rev） |
| 創業 / チーム | 2009年4月（17年）/ 2-20人 |

## 検算で見つけた矛盾
- コンサル実業の実勢は SDE 2〜3倍。9.2x profitは3倍超の言い値
- ここでも契約単価・維持率・顧客集中がすべて非開示（#149/#164と同じ代理店の型）

## 判断
**スキップ**。人的サービス・属人・単価非開示。エコシステム内特化（#057型）はSaaSでこそ効く話で、コンサルは対象外。

## わかりやすく言うと
- **どんなサービス**: 「Salesforce入れたけど使いこなせない」企業の設定・改修を請け負う会社
- **強み**: Salesforce経済圏という安定した釣り堀で17年
- **競合優位性**: 属人。認定資格者が辞めれば終わり
- **日本で始めるなら**: 対象外（受託は既にスマートコネクトでやっている本業側の話）

## 持ち帰った型
なし。観測: **代理店・受託系の出品は3件連続で「契約単価・維持率・顧客集中」を非開示**（#149/#164/#165）— 開示欄の空白自体が業態の弱点の自白
