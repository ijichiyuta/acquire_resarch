# #167 固定料金リクルーティング（$495k, グローバル）— スキップ

## サービスの中身
スタートアップ向けに成功報酬でなく固定料金で採用を請け負う。候補者DB 20万人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $350k / $60k（17%） |
| 先月 | $50k（×12 = $600k、TTM比+71%のスパイク） |
| 顧客数 | 251-500社（単価・維持率非開示 — **5連続**） |
| 年成長率 | +25% |
| 売却理由 | ライフスタイル・時間・新事業（3連） |
| 価格 | $495k（**8.3x profit**） |
| 創業 / チーム | 2019年4月（7.4年）/ 2-20人 |

## 判断
**スキップ**。固定料金でも採用は一件成立型で、リカーリングなし・属人。8.3x profitはサービス業実勢の3倍。

## わかりやすく言うと
- **どんなサービス**: 「1採用いくら」の定額制人材紹介。年収比例の成功報酬より安いのが売り
- **強み**: 価格破壊の切り口と候補者20万人のリスト
- **競合優位性**: リストは陳腐化が速く、固定料金は模倣が一瞬
- **日本で始めるなら**: 対象外（許認可制＋レッドオーシャン）
