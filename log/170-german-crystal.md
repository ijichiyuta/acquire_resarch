# #170 独クリスタルガラス独占輸入EC（$499k, US）— スキップ

## サービスの中身
ドイツ製クリスタルガラス食器の「独占オンライン販売権」を持つEC。SKU600、在庫$125k、DTC＋卸＋ライセンスの全部盛り。

|---|---|
| TTM売上 / 利益 | $383.4k / $119.4k（31%） |

| 年成長率 | +15%（先月×12は+45%） |

| 創業 / チーム | 2022年10月（3.9年）/ 2-20人 |

## 判断
**スキップ**。物販＋在庫＋借入。そして本体資産の「独占販売権」はメーカーとの人間関係で、買収時に再交渉リスクがある最も剥がれやすい資産。売却理由のBusiness challengesが答え。

## わかりやすく言うと
- **どんなサービス**: ドイツの老舗ガラスメーカーの商品を「ネットで独占的に売っていい」権利を持つ輸入商社
- **強み**: 独占権とマージン50-55%
- **競合優位性**: 権利が続く限りは強い。しかし権利は紙一枚
- **日本で始めるなら**: 「海外ブランドの日本独占EC権」という型自体は古典的にあり得るが、権利獲得＝営業力の世界で、うちの型（プロダクトで守る）ではない
