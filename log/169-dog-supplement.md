# #169 犬用サプリのサブスクD2C（$1.3M, US）— スキップ

## サービスの中身
犬用サプリ単品（SKU1、米国製造）のサブスク型D2C。過去にVC調達、現在は広告を絞った収穫モード。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $740k / $360k（**49%**） |
| 先月 | $51k / $26k |
| 顧客数 | 5,000+ / SKU 1 / 在庫$150k |
| 年成長率 | 0%（先月×12 = $612k、実態-17%の緩やか縮小） |
| 売却理由 | 時間不足・新事業 / **VC入り（過去調達）** |
| 競合 | Native Pet / Dog is Human |
| 価格 | $1.3M（3.5x profit / 1.7x rev） |
| 創業 / チーム | 2020年1月（6.6年）/ 2-20人 |

## 判断
**スキップ**。D2Cは対象外だが、標本価値が1つ: **サブスク定期便のD2Cは広告を止めても既存会員から利益率49%のベースが残る**（#150の単品ブーム型と対照的な「良い終わり方」）。ただし買った瞬間から広告再点火の勝負になる点は同じ。

## わかりやすく言うと
- **どんなサービス**: 犬の関節・腸活サプリの定期便。飼い主は解約しない限り毎月届く
- **強み**: 定期便の惰性収益と49%の利益率。ペット市場の深い財布
- **競合優位性**: 弱い。同種サプリは無数で、差はブランドと定期会員リストだけ
- **日本で始めるなら**: 不可（D2C禁止則＋ペットサプリは日本も飽和）

## 持ち帰った型
なし。観測: **「サブスク×消耗品」はD2Cの中では唯一まともに死ねる形**（会員ベースが清算価値になる）
