# #096 クレジットビルダーアプリ（FCA認可）（$2M, UK）— 見送り

## サービスの中身
英国消費者向けに、月£9のサブスクで信用スコア構築＋無利息与信ラインで公共料金を保護するFCA完全認可の消費者信用アプリ。2017年5月創業（9.3年）、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.3M / $100k（**8%**） |
| 先月 | $100k / $13k |
| 顧客数 | 課金5,000+（£9/月） |
| 年成長率 | +5% |
| 売却理由 | **創業者が新会社でY Combinatorに合格**（本業乗り換え） |
| 資金調達 | VC |
| 競合 | Loqbox, Canopy, CreditLadder（正直） |
| 価格 | **$2M（20x profit）** |
| 創業 / チーム | 2017年5月（経過111ヶ月） |

## 判断
**見送り**。FCA認可という規制資産は価値だが、買い手も金融ライセンス保持者に限られ流動性が低い。利益率8%・20x profit。

## タイムマシン評価
**不可**（日本には信用スコア構築市場が制度ごと存在しない＋貸金業登録）。

## 持ち帰った型
なし（「規制ライセンスは堀にも足枷にもなる」の実例）
