# #157 廃棄物・余剰資材の再流通マーケットプレイス（$1.5M, 欧州系）— スキップ

## サービスの中身
企業の廃棄物・余剰資材を再流通させるサブスク型B2Bマーケットプレイス（サーキュラーエコノミー系）。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $437.9k / **-$286.8k（売上の65%を燃焼）** |
| 先月 | $36.5k / -$22.7k |
| 顧客数 / ARR | 10-50 / $329k |
| 客単価 | **月$548〜2,742**（大企業ESG予算） |
| 年成長率 | -11% |
| 売却理由 | ライフスタイル変化 / Bootstrapped |
| スタック | **AngularJS**（レガシー化）/ Azure / AWS |
| 競合 | MatX / iNex EcoSystem Exchange |
| 価格 | $1.5M（3.4x rev、赤字なのに） |
| 創業 / チーム | 2021年12月（4.7年）/ 2-20人 |

## 検算で見つけた矛盾
- 先月×12 = $438k ≈ TTM ✓（整合）。ただし赤字が構造化しており、-11%で縮小しながら3.4x revを要求

## 判断
**スキップ**。単価は本命圏だがESG予算頼みの高コスト運営で4.7年赤字。マーケットプレイスの流動性維持に人手が要る型で個人運用不能。

## わかりやすく言うと
- **どんなサービス**: 「工場の廃材や余った資材、捨てずに他社に売りませんか」のマッチングサイト。企業は月6万〜30万円の会費
- **強み**: ESG・サーキュラーエコノミーの追い風と高単価
- **競合優位性**: 弱い。マッチング成立には営業マンが両側を耕す必要があり、ソフトだけでは回らないことを赤字が証明
- **日本で始めるなら**: 廃材マッチングは日本に複数既存で、そもそも本家が赤字のモデルを輸入する理由がない
