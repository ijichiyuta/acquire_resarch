# #009 Shopify B2B卸売アプリ（$449.2k, India）— 見送り／型に収穫あり

## サービスの中身
Shopifyストアにカスタム開発なしで卸売（B2B）機能を足すアプリ。段階価格・数量割引、卸売バイヤー承認、NET支払条件、顧客グループ、多通貨。$25〜99/月のサブスク、レベニューシェアなし。2024年11月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $100.2k / $81.8k（利益率82%） |
| 先月 | $14.1k / $12.2k（利益率87%） |
| 顧客数 / ARR | 有料474店（総数1,000-5,000はフリー含む） / $165k |
| 客単価 | **月$29**（$165k÷474÷12。プラン$25-99と整合） |
| 年成長率 | +150%（ただし創業21ヶ月のランプアップ込み） |
| チャーン | **1-3%（安定）** ← 低単価なのに#005級 |
| 売却理由 | 新規事業 |
| スタック | Remix / PostgreSQL / AWS / Fly.io / Shopify Polaris（モダン） |
| 資金調達 | ブートストラップ |
| 競合 | **無名のみ**（BSS Commerce等。Shopify本体のネイティブB2B機能を書いていない） |
| 価格 | $449.2k（5.5x profit / 4.5x TTM rev / 2.7x ARR — 検算一致） |
| 創業 / チーム | 2024年11月 / 2-20人（経過21ヶ月） |

## 検算で見つけた矛盾
- 数字自体は整合（先月×12 = $169k ≈ ARR $165k、客単価もプラン価格帯と一致）。今回4件で最もクリーンな開示
- ただし**競合欄が無名だけ**。最大の脅威である Shopify本体のB2B機能吸収（Sherlocking。Shopify PlusのネイティブB2Bを全プランへ下ろす動き）に一切触れていない。150%成長の21ヶ月目に売る理由もこれで説明がつく可能性
- 「一朝一夕に真似できない堀（Built for Shopify認証＋レビュー254件）」はアプリストア内競合には有効だが、プラットフォーム自身には無力

## この事業の強み
販路がShopify App Storeに内蔵（新規顧客の98%がオーガニック）。広告費ゼロで150%成長。5.0★×254レビュー。卸売価格表・顧客グループ・支払条件という**業務設定がアプリ内に蓄積**するため、$29/月でも剥がれない。

## 差別化ポイント
あり（現時点）: Built for Shopify認証＋レビュー資産＋アプリ内の業務設定。ただしプラットフォーム吸収リスクと表裏一体で、消滅は他律的に起こりうる。

## 判断
**見送り**。客単価$29は基準2で赤（$100未満）。5.5x profitは21ヶ月の実績に対して高い。プラットフォーム吸収リスクを売主が開示していない。ただし構造の観察価値は今回4件で最大。

## 持ち帰った型
型4の精緻化（types.md参照）: **チャーンを決めるのは単価ではなく「業務設定・データがプロダクト内に溜まるか」**。$29/月でもチャーン1-3%が成立することを実証した初の案件。あわせて「アプリストア内蔵販路は、買った瞬間から販路が付いてくるが、プラットフォーム自身が競合化するリスクと不可分」。
