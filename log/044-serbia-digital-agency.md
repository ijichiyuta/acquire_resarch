# #044 デジタル代理店10年もの（$96k, Serbia）— スキップ／型1・案1の海外傍証

## サービスの中身
Web制作・ホスティング保守・SEO・広告・AI検索最適化（GEO）を月額で提供する10年ものの代理店。他代理店への白ラベル下請けも。2016年7月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $187k / $64k（34%） |
| 先月 | $11k / $4.5k |
| 顧客数 | 51〜100社、平均契約**$250/月**、維持率**95%** |
| 年成長率 | +34% |
| 売却理由 | 新規事業＋ライフスタイル |
| スタック | PHP / Wordpress / React / AWS ほか |
| 競合 | 無名の同業URL |
| 価格 | $96k（**1.5x profit / <1x rev**） |
| 創業 / チーム | 2016年7月 / 2-20人（経過121ヶ月） |
| 重大リスク | **上位1社への集中40%** |

## 検算で見つけた矛盾
- $250×51-100社×12 = $153k〜300k ≒ TTM $187k ✓ 整合
- 維持率95%・10年という強い継続性が、代理店（労働）であるだけで1.5x profitにしか評価されない — 継続性スペクトラムの「労働はディスカウントされる」面の実例

## 判断
**スキップ**（属人サービス・集中40%）。データ価値: **月$250の保守契約×維持率95%×10年は世界共通で成立している** — 型1・designs.md 案1（保守契約の値上げ装置）の海外傍証。同じ顧客関係でも、労働で回すと1.5x、ソフトで回すと5x（#009）になる。案1で「保守の中身をソフト化していく」方向性の正しさを裏づける。

## タイムマシン評価
**不可（日本に同構造が既にある）**。持ち込むのではなく、自社の保守をソフト化する（案1）が正解。
