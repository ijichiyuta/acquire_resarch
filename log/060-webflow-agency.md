# #060 プロダクト化Webflow代理店（$650k, US Delaware）— スキップ

## サービスの中身
B2B企業（ソフトウェア・ヘルステック）向けに、Webflow制作・SEO・CROを月額リテイナーで提供する「プロダクト化サービス」。2025年9月創業、チーム2-20人。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $436.3k / $217.4k（50%） |
| 先月 | $40.8k / $21.1k |
| 顧客数 | 10〜50社、平均**月$2k**リテイナー、維持率100%表示 |
| 年成長率 | +20% |
| 売却理由 | Other |
| スタック | Webflow |
| 競合 | Veza Digital, Finsweet, Amply（Webflow界の実勢） |
| 価格 | $650k（3x profit / 1.5x rev） |
| 創業 / チーム | **2025年9月 / 2-20人（経過11ヶ月）** |

## 検算で見つけた矛盾
- **経過11ヶ月**なのにTTM表記・「維持率100%」— 1年未満の維持率は何も証明しない
- 11ヶ月の属人代理店に3x profitは強気（#044の10年もの代理店が1.5xだった）

## 判断
**スキップ**。属人サービス。データ価値: 「プロダクト化サービス」の売り方でも代理店の倍率は3xが上限で、ソフト（5.5x）には届かない — 継続性スペクトラムの中間点を埋めるサンプル。**月$2kリテイナー×B2B制作**は案1の海外相場情報として有用。

## タイムマシン評価
**不可**（日本に制作サブスク既存。持ち込むまでもなく自分がやっている業態）。
