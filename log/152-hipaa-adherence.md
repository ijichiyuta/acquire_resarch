# #152 行動医療アドヒアランスSaaS（$88.2k, US）— スキップ

## サービスの中身
行動医療（精神・依存症治療）施設向けに、患者の服薬・治療継続（アドヒアランス）を改善するHIPAA準拠B2B SaaS。ソロ運営8.7年。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $35k / **$1.2k（3.4%）** |
| 先月 | $2k / $1.1k |
| 顧客数 / ARR | <10 / $35k（客単価 月$292+） |
| 年成長率 | +5% |
| チャーン | 0-1% Stable |
| 売却理由 | ライフスタイル変化 / Bootstrapped＋Crowdfunding |
| 競合 | Medisafe / MyTherapy / AdhereHealth |
| 価格 | $88.2k（**73.5x profit** / 2.5x rev） |
| 創業 / チーム | 2017年12月（8.7年）/ ソロ |

## 検算で見つけた矛盾
- 先月$2k×12 = $24k vs ARR $35k（-31%）
- **73.5x profit** は空想倍率の殿堂入り（#129の83.3xに次ぐ2位）
- 8.7年で年利益$1.2k = 事業ではなく維持されている趣味

## 判断
**スキップ**。criteria 0のドメイン降り（医療で出力誤りが患者実害に直結）に加え、8.7年かけて利益が出ない実証済み構造。単価と埋め込み（チャーン0-1%）は本物だが、それでも儲からない市場という反面教師。

## わかりやすく言うと
- **どんなサービス**: 精神科・依存症クリニックの患者が薬を飲み続け通院を続けるよう、リマインドと記録を行うアプリを施設に売る
- **強み**: 解約率ほぼゼロ。医療の規制対応（HIPAA）を8年守り続けた真面目さ
- **競合優位性**: 薄い。Medisafe等の資金調達済み大手が同領域にいる
- **日本で始めるなら**: 不可。医療ドメインは当プロジェクトの即降りレーン（薬機法＋実害リスク）

## 持ち帰った型
なし。観測: **チャーン0-1%でも市場の支払能力が低ければ8年で利益$1.2k** — 「埋め込み」は必要条件であって十分条件ではない、の最良標本
