# #161 不動産SaaS＋マーケットプレイス $10M TTM（価格非公開, US）— スキップ

## サービスの中身
不動産業者向けのマーケットプレイス プレミアム課金＋SaaSサブスクの複合。12年運営、チーム21-100人。「Open to offers」。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $10M / **$200k（2%）** |
| 先月 | $850k / $65k |
| 顧客数 / ARR | 5,000+ / $10M（客単価 月$167） |
| 年成長率 | +286%（12年目でこの数字は手数料のgross計上拡大を疑う） |
| 売却理由 | 「財務的・戦略的機会を検討中」 |
| 資金調達 | Bootstrapped＋Angel＋Strategic |
| 価格 | **Open to offers（非提示）** |
| 創業 / チーム | 2014年10月（12年）/ **21-100人** |

## 検算で見つけた矛盾
- 先月×12 = $10.2M ≈ TTM ✓
- 「Profitable」見出しだが利益率2%。$10M売って$200k＝チーム21-100人の人件費が食い尽くす構造

## 判断
**スキップ**。チーム21-100人の企業規模で個人買収の対象外。#006（不動産MP・チャーン0-1%・利益率高）と同業種の対照標本: **同じ不動産でも「小さく深く」と「大きく薄く」で利益構造が真逆**。

## わかりやすく言うと
- **どんなサービス**: 不動産業者が物件掲載や顧客管理に使う大型プラットフォーム。月2万円弱×5,000社
- **強み**: $10Mの規模と12年の生存
- **競合優位性**: 規模はあるが、利益率2%は「規模でしか守れない」ことの裏返し
- **日本で始めるなら**: 対象外（企業規模の話）。学びは#006と同じ「不動産は小さく深く」

## 持ち帰った型
なし（#006の対照標本として記録）
