# #190 ライフスタイル医学の認定研修（$472.8k, ハンガリー）— スキップ

## サービスの中身
医療従事者向けのライフスタイル医学（生活習慣改善）オンライン研修。CME（医師継続教育）単位認定つき。ソロ運営。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $289k / $172k（60%） |
| 先月 | $24k / $14k（×12 = $288k ✓一致） |
| 顧客数 / ARR | 500-999 / $0（講座買い切り型） |
| チャーン | 0-1%（買い切りなので実質無意味） |

| 創業 / チーム | 2022年9月（4年）/ ソロ |

## 判断
**スキップ**。教育コンテンツ（型3）＋ハンガリー語市場＋医療ドメイン。CME認定という制度フックは面白いが、認定は属人（講師の資格）で移転リスクが大きい。

## わかりやすく言うと
- **どんなサービス**: 医師・看護師が「食事・運動で患者を治す医学」を学ぶオンライン講座。修了すると継続教育の単位になる
- **強み**: 「単位が取れる」という制度フックで利益率60%
- **競合優位性**: 認定と講師の信頼。ただしそれは創業者個人のもの
- **日本で始めるなら**: 不可（医療研修は学会・医師会の縄張りで、部外者の空白がない）

## 持ち帰った型
なし。観測: **「制度単位が取れる教育」はチャーン問題を買い切り型で回避しつつ制度フックで売れる**（案7/10系の制度駆動の変形。ただし認定が属人な点で移転不能）
