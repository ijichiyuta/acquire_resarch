# #005 SMB向けAI人事評価SaaS（$275k, US North Carolina）— 見送り／**型は過去最良**

**サービスの中身**
中小企業向けの人事評価・パフォーマンス管理プラットフォーム。目標設定、1on1、評価サイクルの運用をAIで支援する。B2B専業。2019年8月創業、チーム2〜20人。**7年もの**。

| TTM売上 / 利益 | $159k / $38k（利益率24%） |
| 先月 | 売上$12.4k / **利益 -$2k（赤字）** 🔴 |
| 顧客数 / ARR | **10〜50社** / $144k |
| 客単価 | **月$240〜1,200** 🔵🔵（過去最良・桁が違う） |
| 年成長率 | +10% 🔵 |

| スタック | Python / Spring / React / Java / Kotlin / AWS / OpenAI 🔴 |

| 競合 | Lattice, Leapsome, BetterWorks |
| 価格 | $275k（7.2x profit / 1.7x rev） |

**この事業の強み（ここは本物）**
- **チャーン1-3%**。5件見た中で圧倒的に最良。人事評価は一度入れると業務プロセスに埋め込まれるので剥がれにくい
- **客単価が月$240〜1,200**。#001〜#004が月$2〜54だったのに対して**桁が2つ違う**
- 顧客がたった10〜50社でARR $144k。少数の法人と深く付き合う構造
- 競合に Lattice / Leapsome / BetterWorks という本物の大手をきちんと書いている。**開示が誠実**（#002/#003は大手を隠していた）

**見送りの理由**
- **先月が -$2k の赤字**。見出しは「75% Operating Margins, Profitable」だが、TTM純利益率は24%、直近月は赤字。**見出しの数字と実数字が食い違っている**
- 売主は「2.3x ARR」と説明しているが、$275k ÷ $144k = 1.9x で自分で計算すると合わない。ARRも見出しの$148kと実数の$144kでズレている
- **Financing欄が4つ全部チェック**。借入・エンジェル・VCが本当に入っているなら、$275kの小規模買収には複数の同意と債務処理が必要になり、成立させにくい
- **創業2019年＝7年で年商$159k、成長率10%**。天井に当たって止まっている
- スタックが Java / Kotlin / Spring / Python / React の多言語構成。2〜20人のチームで維持してきたもので、個人が引き継げる規模ではない
- B2B人事SaaSは営業主導。成長施策に「Hire a sales team」がある通り、**優太さんが持っていないチャネルが前提**

**差別化ポイント**
製品機能ではなく**乗り換えコストの高さ**。評価データが蓄積され、人事プロセスに組み込まれるので、多少不満でも剥がせない。チャーン1-3%はその結果。

**持ち帰った型: → 型4（下記）。これが5件で最大の収穫。**
