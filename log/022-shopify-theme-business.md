# #022 Shopifyテーマ販売事業（$2.7M, Turkey）— 見送り／倍率の学びあり

## サービスの中身
公式Shopify Theme Storeで複数テーマを販売する13年もののデジタル商品事業。マーケ費ゼロ・全売上オーガニック。サポート1名は残留意思（買い手が北米なら）。2013年1月創業。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $1.5M / $1.4M（**利益率93%**） |
| 先月 | $88.6k / $77.1k |
| 顧客数 / ARR | 5,000+ / 「ARR $840k」表記（下記参照） |
| 客単価 | テーマ買切り$200-400程度（一回性） |
| 年成長率 | +5% |
| チャーン | 10%+表記（買切り商品なので概念が不適合） |
| 売却理由 | 家族の事情＋金銭＋ライフスタイル |
| スタック | Shopify |
| 資金調達 | ブートストラップ |
| 競合 | Archetype, Clean Canvas, Fluorescent 等（テーマ工房の実勢を正直に列挙） |
| 価格 | $2.7M（**2x profit / 1.8x rev**） |
| 創業 / チーム | 2013年1月 / 2-20人（経過163ヶ月） |

## 検算で見つけた矛盾
- **先月×12 = $1.06M vs TTM $1.5M（-29%）** — 2023年に3倍化→2024年安定と説明するが、直近は下降局面
- 「ARR $840k」— テーマは買切りでrecurringではない。ARR欄とチャーン欄が商品特性と不適合のまま埋められている
- 売上はShopifyの手数料15%控除後のネット表記（ここは誠実）

## この事業の強み
93%マージン・13年生存・公式ストア内の地位とレビュー資産。代理店のリピート購入。

## 差別化ポイント
ストア内ブランドのみ。Shopify本体の無料テーマ（Dawn）とストアのアルゴリズム・規約変更が常時リスク。

## 判断
**見送り**（規模$2.7Mは対象外。構造データとして採取）。

## 持ち帰った型
型は拾わないが**倍率の学び**: 同じ「ストア内蔵販路」でも、#009（サブスクアプリ・チャーン1-3%）は5.5x profit、#022（買切りテーマ）は2x profit。**市場は「収益の継続性」に2.5倍以上の価格差をつける**。作るなら買切りではなく、設定が溜まるサブスクにする根拠がここにもある。
