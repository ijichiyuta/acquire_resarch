# #031 州内学費資格取得支援PF（$1.2M, US Texas）— スキップ／「制度ワークフロー×高ROI」をメモ

## サービスの中身
公立大の州内学費（in-state tuition）の居住要件を、ワークフローソフト＋専門家アドバイザリーで合法的にクリアさせる。家族にとって数万ドルの学費差＝ROIが明確。1州のみ・1人運営。2022年9月創業。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $388.6k / $365k（**利益率94%**） |
| 先月 | $32.4k / $30.4k |
| 顧客数 | アクティブ101〜250（単発エンゲージメント） |
| 客単価 | 案件$1,500〜3,800（単発） |
| 年成長率 | 0% |
| チャーン | 概念不適合（単発） |
| 売却理由 | 新規事業 |
| スタック | React |
| 資金調達 | ブートストラップ |
| 競合 | 「hilltopmonitor.com」（ニュースサイト。無意味な開示） |
| 価格 | $1.2M表示 vs 根拠欄$1.35M（**価格自体が2箇所で不一致**）。3.4x profit |
| 創業 / チーム | 2022年9月 / 1人（経過47ヶ月） |

## 検算で見つけた矛盾
- 表示価格$1.2M vs 根拠欄$1.35M
- カテゴリはAgency・実態はB2C単発サービス（「SaaS」ではない）。94%マージンの源泉は創業者自身のアドバイザリー労働

## 判断
**スキップ**。単発×属人×成長0%×1州依存（制度変更リスク）。

## 持ち帰った型
types正式追加はしないがメモ: **「制度の複雑さ」そのものを商品化し、顧客ROI（数万ドル）から価格を取る**構造は強い。日本の対応物は士業独占資格の壁に当たりやすいが、**士業と組んで（案2の販路）ワークフロー部分だけをSaaS化する**形なら独占業務に触れない。designs.md 案2/案4の傍証。
