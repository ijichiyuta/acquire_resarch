# #204 アルバム校正SaaS（$75k, 欧州系）— スキップ

## サービスの中身
ウェディングカメラマンと顧客の間でアルバムのレイアウト確認・修正指示をやり取りするツール。月$29または1アルバム$12のクレジット制。12.8年運営。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $30k / $30k（利益率100%＝自分の労働を経費計上せず） |
| 先月 | $3.1k / $3k（×12 = $37k） |
| 顧客数 / ARR | 101-250 / $23k（単価 月$8〜19） |
| 年成長率 | -7% |
| 売却理由 | 「自分の必要から作った」（ウェディングカメラマン本人） |
| 価格 | $75k（2.5x profit） |
| 創業 / チーム | 2013年11月 / 2-20人 / Ruby on Rails |

## 判断
**スキップ**。#191（フォトブース）・#203（カメラマンCRM）と同じ写真業界マイクロ縦。12.8年生存は「プロの作業ツール」の粘りの証明だが、-7%・月$19以下・年商$30kは事業でなく副業。

## わかりやすく言うと
- **どんなサービス**: 「アルバムのこのページ、写真差し替えて」を客とやり取りする専用ツール
- **強み**: 作者自身が現役カメラマン（#071型の王道）
- **競合優位性**: ニッチすぎて競合も来ないが客も増えない
- **日本で始めるなら**: 不可（市場が小さすぎる）

## 持ち帰った型
なし（写真業界3連で確認: **マイクロ縦の「プロ日常ツール」は長生きするが、単価の天井が月$26**）
