# #001 ブログSaaS（$27k, US Delaware）— スキップ

**サービスの中身**
企業が自社サイト上でブログを公開・管理するためのB2B基盤。WordPressを立てずに済ませたい中小企業が対象。年間プラン課金。2022年10月創業、1人運営。

|---|---|
| TTM売上 / 利益 | $15.1k / $12.7k（利益率84%） |
| 先月 | 売上$1.2k / 利益$997 |
| 顧客数 / ARR | 251〜500 / $12k |
| 客単価 | **月$2〜4** 🔴 |
| 年成長率 | **-32%** 🔴 |
| チャーン | 3-5% stable |
| 売却理由 | Other / Starting a new venture / **Business challenges** 🔴 |
| スタック | **PHP (CodeIgniter 3) + jQuery** 🔴 |
| 競合 | Ghost, Substack, Medium, WordPress |
| 価格 | $27k（2.1x profit / 1.8x rev） |

**この事業の強み**
- 利益率84%、インフラ費が月$200程度。個人運営で回る軽さ
- サポートチケットが少ない。手離れが良い
- 年間プランなので解約タイミングが年1回に固定され、キャッシュフローが読める

**差別化ポイント：なかった**
これが敗因。Ghost・Substack・Medium・WordPressという4方向の巨人に対し、「安い汎用ブログ」以外の理由がない。だから単価が月$2〜4まで落ち、値上げもできず、-32%で縮んだ。**顧客が「これでなければ困る」理由を1つも持てなかった案件。**

**判断: スキップ。** 基準1〜4が全て赤。詳細を読む価値がなかった。
