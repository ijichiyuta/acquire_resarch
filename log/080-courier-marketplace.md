## サービスの中身
企業チームの同日ローカル配送（バイク便）とFedEx/UPS支出を一元管理するマーケットプレイス。出荷ごとのテイクレート。2021年2月創業、チーム2-20人。

| TTM売上 / 利益 | $228.2k / $52.6k（23%） |
| 先月 | $22.8k / $7.4k |
| 顧客数 / ARR | 1,000-5,000 / ARR $0（取引型・正直） |
| 年成長率 | 0% |
| チャーン | 10%+（リピート79%と併記） |
| 売却理由 | 新規事業 |

| 創業 / チーム | 2021年2月 / 2-20人（経過66ヶ月） |

## 判断
**スキップ**。成長0%の取引型に16.9x profitは交渉の入口にならない（#048と同類の空想価格）。
