# #142 WordPressテーマ・ツール会社（$365k, ルーマニア）— スキップ

※本来#142として収穫した「サブスクWeb制作・管理（$130k利益）」はURL消失。候補URLを開いたところ本件だったため、判定順で#142を付番。

## サービスの中身
代理店・企業向けにWordPressのプレミアムテーマ・サイト構築ツール・デザイン素材・ライセンスを販売。2019年から運営、**有料顧客25,000超**。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $225.6k / $34k（15%） |
| 先月 | $22.1k / $5.3k（24%） |
| 顧客数 | 25,000+ |
| 客単価 | **年$9 = 月$0.75**（$225.6k÷25,000） |
| 年成長率 | +6% |
| 価格 | $365.5k（**10.7x profit** / 1.6x rev） |
| 創業 | 2019年（経過約7年） |

## 検算で見つけた矛盾
- 先月×12 = $265k vs TTM $225.6k（+17%）— 6%成長表記と概ね整合、問題なし
- 10.7x profit は実勢（3〜4x）の約3倍の空想値付け

## 判断
**スキップ**。客単価月$0.75は基準2の赤（月$5未満）で一発終了。25,000人を集めて月$19kは「多数×低単価」の教科書標本。

## わかりやすく言うと
- **どんなサービス**: WordPressでサイトを作る人向けの「テーマ（デザインの型）と部品」の販売店。1個数十ドルの買い切り〜低額サブスク
- **強み**: 7年の運営と25,000人の顧客リスト
- **競合優位性**: なし。テーマ販売はEnvato等の巨大市場で価格競争、しかもAIビルダーとWordPress離れで市場自体が縮小方向
- **日本で始めるなら**: 開発は安い（テーマ制作のみ）が、25,000人集めても月200万円にしかならない構造そのものが罠。始める価値なし
