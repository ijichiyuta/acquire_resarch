# #238 白ラベル・コミュニティSaaS（$235k, 国不明）— スキップ

## サービスの中身
「自社ブランドのオンラインコミュニティ」を作れる白ラベル基盤（Circle対抗）。ソロ、2023年9月創業。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $165k / $137.5k（83%） |
| 顧客 / ARR | **10社 / $18k（TTMと9倍乖離＝構築受託の一括が大半）** |
| チャーン | 10%+ |
| 見出し | 「Just Add Sales（営業を足すだけ）」＝営業チャネル不在の自白 |
| 価格 | $235k（1.7x profit） |

## 判断
**スキップ**。#185（白ラベルメール、継続$280k）との対照が鮮やか: 同じ「白ラベル」でも、**継続収益が実在するか（$280k vs $18k）が全て**。これは受託の売上をSaaSの顔で売る案件。

## わかりやすく言うと
コミュニティサイトを作ってあげる受託屋。「白ラベルSaaS」の看板だが、毎月入るのは18万円。

## 持ち帰った型
なし（白ラベル判定には「継続ARRの実在」を必須条件に追加）
