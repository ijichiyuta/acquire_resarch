# #231 大学向けAIエンゲージメント・リード獲得SaaS（$1.4M, US）— 見送り

## サービスの中身
大学の入学希望者対応（AIチャット・リード捕捉・エンゲージ）SaaS。「6年間チャーン0%」を主張。

| 項目 | 値 |
|---|---|
| TTM売上 / 利益 | $249.3k / $206.3k（**83%**） |
| 先月 | $33.6k / $21.1k（新学期前の年払い集中か） |
| 顧客 / ARR | **10-50大学 / $226k（単価 月$377〜1,883）** |
| チャーン | **0-1%（6年）** |
| 年成長率 | +67% |
| 競合 | Ivy.ai / Element451 / Mainstay / Ocelot |
| 価格 | $1.4M（6.6x profit / **5.4x rev**） |
| 創業 | 2019年5月（7.3年）/ 2-20人 |

## 判断
**見送り**。構造は255件中最良級の型4（少数×高単価×チャーン0×高利益率×7年）。落とす理由は一点: **売上の5.4倍という値付け**（実勢の2倍超）。売主も価値を理解している＝掘り出しではない。

## わかりやすく言うと
大学の「入学案内チャット」。大学は一度入れたシステムを止めない（調達の惰性）ので解約ゼロ。良い商売はやはり教育・行政のような**調達が遅い顧客**に宿る。

## 持ち帰った型
観測: **「調達慣性による埋め込み」** — 教育機関・行政は導入障壁が高い代わりに解約もしない。#005（人事評価）の変形として、日本なら私立大学・専門学校の学生募集DXは型4候補の縦（ただし競合要検証・営業チャネルが独特）
